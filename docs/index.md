# Scenex documentation

Scenex is a web platform for writing and running megagames — live,
facilitated performances in which groups make decisions under pressure and
see the consequences on the wall.

## For authors and game masters

**[The Scenex Tutorial](tutorial/index.md)** — the whole platform, step by
step, with the *Mars Colony* scenario as the worked example.
