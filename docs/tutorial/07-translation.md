# 7. Translating a scenario

[← Labels, endings, pages, media and members](06-more-content.md) · [Contents](index.md) · [Next: The dry run →](08-dry-run.md)

Every text the players see can exist in several languages: names, titles,
narratives, option texts, endings, pages. Scenex currently supports English,
German, Spanish, Estonian, Hungarian, Italian, Norwegian, Polish and
Portuguese.

## The working locale

The **Working locale** row at the top of the editor chooses which language
you are editing. Switch to `de`, and every text field shows (and saves) its
German version:

![The Engineering group with the working locale set to German](images/translate-de.png)

Empty fields are simply not translated yet. Handles, keys, numbers, formulas
and conditions are the same in every language — you only translate text.

## Fallback

You don't have to translate everything at once. If a text is missing in the
session's language, Scenex shows the **source locale** version instead (the
language set in *Settings*), so a half-translated scenario never shows blank
spaces.

## Which language does the room see?

You choose the **play language** when you create a session
([chapter 9](09-sessions.md)). The group boards, the projected display and
the content in the GM console use that language. The buttons and menus of
the editor and the console are in English.

## Tips

- Write the whole scenario in one language first, test it with a dry run,
  and translate when the content is stable — every later change has to be
  made in every language.
- Option texts are short. Check that the translation still fits on a phone.
- Director's notes can stay in the GM's language; players never see them.
