# 12. Show-day checklist and troubleshooting

[← What the room sees](11-player-screens.md) · [Contents](index.md) · [Appendix: Mars Colony →](mars-colony.md)

## The week before

- [ ] Do a full **dry run** ([chapter 8](08-dry-run.md)) with the final
      content. Note which endings your test runs reached.
- [ ] Do one **rehearsal session** with friends or colleagues: real devices,
      real projector, real QR codes. Delete nothing — rehearsal sessions are
      harmless.
- [ ] Read every director's note aloud once. Do you know who gets which
      Wildcard card?
- [ ] Print the Wildcard mission cards (their narratives) and any other
      props.

## On the day

- [ ] Wi-Fi: every table device and the projector computer must reach
      scenex.org. Test it in the room.
- [ ] Create the session with tonight's label, language and groups
      ([chapter 9](09-sessions.md)).
- [ ] Generate all codes, **Download all as PDF**, print, place one code per
      table.
- [ ] Open the display link on the projector computer, full screen.
- [ ] Charge the table devices. Open each group's code once to check it.
- [ ] Put up the *Welcome* page.
- [ ] Have the run sheet (the scenario's director's notes) at hand.

## During the show

- Start the session only when the room is ready — the game clock starts with
  it.
- **Pause** when you need to stop the story (a long discussion, a break).
  Deadlines freeze while paused.
- Read narratives aloud as you fire beats; not everyone reads their board.
- Use the director's notes in the console as your prompt book.
- Count Morale at the moments the notes suggest; the room loves seeing
  its own mood on the wall.

## Troubleshooting

| Problem | What to do |
|---|---|
| A table's board shows nothing | Has the beat been triggered? Do they have options in it? Reload the page. |
| A table chose by accident | Enter the right option in the console — the last decision counts. |
| A table can't choose an option | It is probably gated (greyed out, condition shown). Override from the console if you want to. |
| The display is frozen | Reload it. Nothing is lost; it shows the current state. |
| The laptop crashed | Open the console again from the sessions list. Everything is still there. |
| A code leaked | **Revoke** it and generate a new one. |
| Time is running out | Skip beats. Mars Colony works without Wildcards and without the Vote. |
