# 13. Show-day checklist

[← What the room sees](12-what-the-room-sees.md) · [Contents](index.md) · [Appendix: Common Ground at a glance →](common-ground.md)

## The week before

- [ ] Click through the whole show once in the [dry run](09-dry-run.md) — in
      the language you'll play in.
- [ ] Do a **rehearsal session** with friends or colleagues: real tablets,
      real projector, real QR codes. Rehearsal sessions are harmless — make
      as many as you like.
- [ ] Read every director's note once, out loud. Who gets which card? Which
      version of which Key Event?
- [ ] Print what happens on paper: slogans, candidate scripts, Wildcard
      cards.

## On the day

- [ ] **Wi-Fi.** Every tablet and the projector computer must reach
      scenex.org. Test it in the actual room.
- [ ] Create tonight's session — name, language, groups.
- [ ] Make all codes, **Download all as PDF**, print, one code per table.
- [ ] Open the projector link on the projector computer, full screen.
- [ ] Charge the tablets. Open each table's code once to check it.
- [ ] Put up the title page.
- [ ] Keep the console open on your laptop, with the director's notes close.

## During the show

- Start the session only when the room is ready — the clock starts with it.
- **Pause** whenever the story needs to stop: a long debate, a break. All
  countdowns wait.
- Read the narratives aloud as you fire the beats. Not everybody reads their
  board.
- Ask the room how it feels — more than once. Seeing its own mood on the wall
  is a moment people remember.
- Trust the room. The beats are a menu; you choose what happens next.
